# hangul-willow

능수버들 아래 살랑이는 한글.  
Hangul fluttering under the weeping willow.

`hangul-willow` is a small interactive canvas experiment where Korean letters drift like leaves in the wind. The text input stays modern, while the drifting output is rendered with an archaic Hangul style inspired by Middle Korean writing.

## Run

Open `index.html` in a browser.

No build step or package install is required for the current version.

## Controls

- Edit the phrase to change which Hangul characters appear.
- Adjust wind and density to reshape the motion.
- Pause or restart the flow from the control panel.

The current archaic style is visual rather than a scholarly Middle Korean translation. It mixes old Hangul jamo and hand-drawn bangjeom-like tone dots for atmosphere.
